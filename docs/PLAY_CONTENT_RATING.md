# Google Play — Content rating questionnaire (preparation)

Play Console → App content → Content rating (IARC questionnaire). Category to choose: **Utility, Productivity, Communication, or Other**
(not a game, not social, not a news app).

Expected answers for WorkEarn 1.0.0:

| Topic | Answer |
| --- | --- |
| Violence / blood / gore | No |
| Sexual content or nudity | No |
| Profanity or crude humour | No |
| Controlled substances (drugs, alcohol, tobacco) | No |
| Gambling or simulated gambling | No |
| Fear / horror themes | No |
| User-generated content or user interaction / sharing with other users | No (all data is private to the device) |
| Shares the user's physical location with other users | No |
| Allows users to purchase digital goods | No |
| Contains ads | No |
| Collects personal information from users | No (see `docs/PLAY_DATA_SAFETY.md`) |

Expected result: the lowest age band (IARC "3+" / ESRB "Everyone" / PEGI 3). The final rating is assigned by the questionnaire in the Play
Console, not by this document.

Target audience and content: **18 and over** (a tool for workers), not designed for children, so the *Families* policy does not apply.
